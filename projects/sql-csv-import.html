Overview

A complete SQL-based analytics project built on healthcare billing data. The goal was to analyze patient counts, item usage (medicines, consumables), and doctor-level distributions using optimized SQL queries.

Tech Stack

SQL · SQLite / MySQL · Python · Flask · CSV Import · Pagination

Key Features

  • Distinct patient count validation
  • Doctor-wise patient and item aggregation
  • CSV import verification
  • Web interface with pagination

What I Learned

This project strengthened my understanding of real-world SQL, JOIN-heavy queries, data validation, and building a backend-driven UI.
