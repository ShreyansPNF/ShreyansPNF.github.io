Overview

A lightweight Flask web application that displays large SQL tables through a paginated interface using Jinja2 templates.

Features

  • Server-side pagination
  • Dynamic page navigation
  • CSV-to-SQL import validation
  • Clean tabular UI

Why It Matters

This project bridges raw databases and user-friendly interfaces, showing how backend data becomes usable information.
